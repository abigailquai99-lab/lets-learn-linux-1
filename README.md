# Linux CLI Survival Kit — DevSecOps Field Assignment

Project Overview

This project was a hands-on Linux and DevSecOps practice assignment focused on using the command line to manage systems, files, logs, permissions, and filesystem structures.

The goal was to simulate real DevSecOps tasks performed when working on servers, troubleshooting environments, and preparing systems for automation.

Skills Practiced

- Linux navigation and system identification
- Filesystem Hierarchy Standard (FHS)
- Directory and file management
- Log creation and troubleshooting
- Input/output redirection
- File permissions and ownership
- Hard links and symbolic links
- Inodes and filesystem concepts
- Basic DevSecOps automation practices
